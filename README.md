# JavaScript Basics Project

This is a small JavaScript practice project containing simple console programs, a recursive algorithm example, and a few text files used for experimentation.

## Project Contents

### `test.js`

The main example script prints a greeting to the console:

```text
Hello World
```

Run it with:

```bash
node test.js
```

### `fibonacci.js`

This script defines a recursive `fibonacci(n)` function. It calculates the Fibonacci number at a given zero-based position and demonstrates the function with `n = 6`.

Run it with:

```bash
node fibonacci.js
```

Its output is:

```text
Fibonacci of 6 is: 8
No more comments
```

### Text files

The repository also contains a few small text files for basic file and content experiments:

- `msg.txt` contains sample text and numbers.
- `example2.txt` contains a short change note.
- `prueba.txt` and `example3.txt` are currently empty.

## Requirements

- Node.js

No package manager, dependencies, build system, or test framework is configured. The JavaScript files can be run directly with Node.js.
